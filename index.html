スプレッドシート（GAS）設定

先生がつくった Google Apps Script の URL をはりつけて「ほぞん」をおしてください。

スプレッドシート側の じゅんび手順

  1. きろくしたい Googleスプレッドシート を開きます。
  2. メニューの「拡張機能」＞「Apps Script」をえらびます。
  3. がめんに 下のコードを はりつけて ほぞんします。
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  
  if (sheet.getLastRow() === 0) {
    sheet.appendRow(["日時", "学年・組", "氏名", "距離", "タイム", "メモ"]);
  }
  
  sheet.appendRow([
    data.date,
    data.runnerClass,
    data.runnerName,
    data.distance,
    data.time,
    data.memo
  ]);
  
  return ContentService.createTextOutput(JSON.stringify({result: "success"}))
    .setMimeType(ContentService.MimeType.JSON);
}
  1. みぎうえの「デプロイ」＞「新しいデプロイ」をクリックします。
  2. 「ウェブアプリ」をえらびます。
  3. アクセスできるユーザーを「全員 (Anyone)」にして「デプロイ」を押します。
  4. 出てきた「ウェブアプリ URL」をコピーして、上の入力らんにはりつけます。
